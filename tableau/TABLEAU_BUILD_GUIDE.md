# Tableau Build Guide

## Final Dashboard Standard
Use the same clean standard as Project 3: white background, thin light-gray borders, 6 KPI cards and exactly 6 visualizations in a 3 x 2 grid.

### Color standard
Use only these 3 visualization colors throughout the dashboard:
- Blue
- Teal
- Orange

Do not introduce additional chart colors.

### Date standard
Use MM/YY dates such as 07/26.

### KPIs
1. Total Screenings
2. Potential Matches
3. High-Risk Matches
4. True Matches
5. False Positives
6. Payment Volume

### Six Visualizations
1. Screening Alert Trends — combined lines for Screening Alerts, Escalated, and True Matches.
2. Screening Disposition — donut.
3. Top 5 Countries by Flagged Amount — vertical bar chart.
4. Screening Activity Heatmap — 7 days x 8 three-hour blocks. Counts must appear clearly inside every cell.
5. Name Match vs Screening Risk — scatter plot.
6. Top Sanctions Programs — horizontal bar chart.

### Heatmap requirements
- Rows: Mon–Sun.
- Columns: 00–02, 03–05, 06–08, 09–11, 12–14, 15–17, 18–20, 21–23.
- Use a clean sequential blue/teal scale.
- Show the count centered in every cell.
- Keep cell borders visible.
- Avoid 24 cramped hourly columns.


## Separate KPI Visualization
Create a standalone KPI scorecard worksheet/dashboard in addition to the 6-chart executive dashboard.

The KPI scorecard should show:
1. Total Screenings
2. Potential Matches
3. High-Risk Matches
4. True Matches
5. False Positives
6. Payment Volume

Use the same three-color standard: blue, teal, and orange.
Keep the KPI scorecard separate from the six main analytical charts.
